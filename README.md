# Brick Breaker

## Sobre o projeto

Aplicativo móvel desenvolvido para a disciplina de Projeto Integrador VI-A, com base no clássico jogo Brick Breaker (Breakout). O projeto tem como objetivo aplicar conceitos de desenvolvimento mobile, design de interfaces, usabilidade e interação com recursos do dispositivo.

O jogo permite ao usuário controlar uma plataforma para rebater uma bola e destruir blocos distribuídos em diferentes níveis. O aplicativo conta com 5 fases, diferentes padrões de paredes de tijolos, geração de espaços aleatórios, sistema de colisão, pontuação, sons e opções de configuração de cores e tamanhos dos tijolos.

O projeto também contempla telas de menu inicial, integrantes, configurações, gameplay, transição de níveis, vitória e Game Over, proporcionando uma experiência completa e intuitiva ao usuário.
